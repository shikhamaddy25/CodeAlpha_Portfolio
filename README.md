# 💼 Personal Portfolio Website

A modern, responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my technical skills, projects, education, and resume.

This portfolio represents my learning journey in web development and software engineering.

## ✨ Features

- 🎨 Modern and clean dark-themed user interface
- 📱 Responsive design for desktop, tablet, and mobile devices
- 👩‍💻 About Me section to introduce my background and interests
- 🛠️ Skills section highlighting technical skills
- 🚀 Projects section with project descriptions and GitHub links
- 📄 Resume section with options to view and download my resume
- 📬 Contact section with professional profile links
- ✨ Smooth scrolling, hover effects, and interactive navigation

## 🧰 Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsiveness
- **JavaScript** — Interactive elements and navigation
